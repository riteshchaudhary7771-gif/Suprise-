# Birthday Surprise Website

A mobile-friendly, interactive birthday scrapbook inspired by the supplied reference video.

## Open it
1. Extract `birthday_surprise_website.zip`.
2. Open `index.html` in a browser, or upload all three files (`index.html`, `style.css`, `script.js`) to a GitHub repository.
3. In GitHub, open **Settings → Pages**, select the main branch and root folder, then save.

## Personalize it
- Open `script.js` and change `const PASSCODE = "1234";` to a four-digit passcode.
- Edit the birthday text in `index.html`.
- The memory cards and portrait cards are decorative placeholders. Replace them with your own photos to personalize the site.
- You can change colors and fonts in `style.css`.

## Note
This is a close recreation of the visible layout and interactions from the video, not the original source website. Original private photos, music, exact passcode, and any unseen animations are not included.
